# เครื่องมือเวร EP

หน้าเว็บช่วยวางแผนเวรของทีมแพทย์ฉุกเฉิน เป็น HTML ล้วน ไม่มี build step ไม่มี dependency
เปิดไฟล์ตรงๆ ในเบราว์เซอร์ก็ใช้ได้ หรือวางบน GitHub Pages ก็ได้

จัดทำโดย นพ.ณัฏฐ์ จักร์ขจรวัฒน์ EP รพ.ระยอง

## โครงสร้าง

```
index.html        หน้ารวมลิงก์ (หน้าแรกของเว็บ)
ep-shift/
  index.html      เครื่องคำนวณภาระเวร EP
```

## วิธีแก้ไข

1. เข้า repo นี้บน github.com
2. กดเข้าไฟล์ที่จะแก้ → ปุ่มดินสอ (Edit this file)
3. แก้เสร็จกด **Commit changes**
4. รอประมาณ 1 นาที เว็บอัปเดตเอง URL เดิม

ถ้าได้ไฟล์ใหม่มาทั้งไฟล์ ใช้ **Add file → Upload files** แล้วลากไฟล์ไปวางทับชื่อเดิมได้เลย
GitHub จะถือว่าเป็นการแก้ไขไฟล์นั้น ประวัติเก่ายังอยู่ครบ

## เพิ่มเครื่องมือใหม่

1. สร้างโฟลเดอร์ใหม่ เช่น `ชื่องาน/` แล้ววางไฟล์ `index.html` ไว้ข้างใน
2. เพิ่มลิงก์ในบล็อก `.tools` ของ `index.html` หน้าแรก โดยก๊อปปี้ `<a class="tool">` อันเดิมมาแก้
3. URL จะเป็น `.../ชื่องาน/`

## หมายเหตุทางเทคนิค

- ค่าที่ผู้ใช้ปรับไว้เก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง ไม่ได้ส่งออกไปไหน
  คีย์ของเครื่องคำนวณคือ `ep-load-v2` (ธีมเก็บที่ `ep-load-v2-theme`)
- ฟอนต์โหลดจาก Google Fonts ถ้าออฟไลน์จะ fallback เป็นฟอนต์ไทยของระบบ ใช้งานได้ปกติ
- รองรับโหมดมืดตามเครื่อง และมีปุ่มสลับธีมเองที่มุมขวาบน
